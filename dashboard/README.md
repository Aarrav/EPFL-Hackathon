# Dashboard

Open `lerobot_dashboard.html` in a browser to view the camera panel and ESP32 harvest counter.

By default it connects to `ws://10.183.143.188/ws`. Override that without editing the file:

```text
dashboard/lerobot_dashboard.html?ws=ws://ESP32_IP/ws
```

`legacy/` contains imported dashboard copies kept for reference. Use the top-level `lerobot_dashboard.html` for normal operation.
