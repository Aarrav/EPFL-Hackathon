# Data Assets

- `yolo/my_model.pt` is the trained Ultralytics YOLO model used by the live detection scripts.
- `yolo/data.zip` is the dataset archive used during training.
- `captured_images/` contains sample captured images from the hackathon run.
- `local_captures/` is the default ignored output folder for new captures.

Set `CAPTURED_IMAGES_DIR` in `.env` if you want to save captures somewhere else.
